- 대상: `geonjuring/AX-Hackathon` (Public, 업로드 전 확인)
- 원본: `lot_agent_releases/20261107_2155`의 통합 앱과 경영 리포트 스냅샷
- 포함: Python 코드·테스트·의존성·Streamlit 테마·실행 스크립트·설명 문서·빈 환경변수 예시
- 제외: 원본/정제 CSV, 직원 명부, DuckDB, Parquet 캐시, 실제 다운로드 ZIP, 로그, PID, 서버 운영 현황 파일, 가상환경, 실제 `.env` 및 인증정보
- 원본 실행 폴더와 실행 중인 서비스는 수정하지 않았습니다.
- 제출용 복사본은 데이터·DB·Python 실행 경로를 다른 환경에서도 설정할 수 있게 정리했습니다. 계산 로직은 유지했습니다.
- 최신 AgentStream 수정은 `slp/ai/agentstream/context.py`, `slp/ai/agentstream/client.py`, `tests/ai/test_agentstream.py`에 반영했습니다. 경영 리포트 폴더, 통합 메뉴·실행 경로, 계산 엔진, 데이터 준비 코드와 의존성은 이번 변경에서 유지했습니다.
- 서버 전용 키 입력·프로세스 교체 스크립트와 런타임 상태 JSON은 업로드하지 않습니다. 범용 실행·키 주입 절차는 `docs/DEPLOYMENT.md`에 작성했습니다.

## 검증 결과와 한계

- 분석·API·재생·다운로드 단위 테스트: 37개 통과
- 경영 리포트 단위 테스트: 36개 통과
- 합계 73개 통과. Python 3.12.3, 팀 서버의 별도 후보 소스 폴더에서 실행했으며 운영 DB·키를 테스트에 사용하지 않음
- Python 소스 47개 구문 분석 통과
- 실제 기업 데이터·직원 데이터·DB·캐시·로그·생성 리포트를 업로드 목록에서 제외
- 실제 팀 AgentStream 공개·CHAT_INVOKE 저장, 가상 첫 질문·후속 답변 및 공용 LOT 화면의 실제 분석 첫 질문·후속 답변 완료 확인. ZIP의 HTML·JSON에 마지막 실제 답변 보존 확인. 이 배포 검증과 합성 데이터/대역 API 단위 테스트는 별개
- 답변의 규격·예측·출처 표현은 추가 검토가 필요함. 생성 완료를 사실 정확성 검증 완료로 표시하지 않음
- 설치 패키지는 기존 검증 가상환경을 사용함. 신규 기기 설치·실제 API 장기 안정성·시연 화면 전체 동작은 이번 검증 결과에 포함하지 않음
- `.gitignore`는 실수 방지 보조 수단임. 이후 추가 파일도 커밋 전에 내용을 확인할 것

첨부 체크리스트에서 코드 공개나 통합 자체를 금지하는 항목은 확인되지 않았습니다. 다만 실제 기업 데이터나 비밀정보를 함께 공개하면 첨부 요건에 맞지 않습니다. 별도 대회 약관과 기업 데이터 재배포 조건은 원문이 제공되지 않아 판단을 보류합니다.
