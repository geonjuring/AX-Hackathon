# 폴더 정리와 시연 검증

2026-11-08. 기준 소스는 GitHub `main`의 `e04df9046a748ee51e28d94b2e9dfbe0b98209d1`입니다. 정리 전 소스는 `backup/pre-folder-organization-e04df90` 브랜치에 보관했습니다.

## 변경 범위

- 루트의 화면·계산·AI·공통 모듈을 `slp/`의 역할별 패키지로 이동했습니다.
- 기존 경영 리포트는 `slp/management/`, 경영 화면은 `slp/ui/management_page.py`로 편입했습니다.
- DB 준비와 운영 점검은 `scripts/prepare/`, `scripts/checks/`로 이동했습니다. 루트에서 `python -m scripts.prepare.prep`처럼 실행합니다.
- 모든 테스트를 `tests/`로 모으고 import와 mock 대상 경로를 함께 수정했습니다.
- `unified_app.py`, `app.py`, `bash run.sh`, 기존 메뉴 URL과 환경변수는 유지합니다. 경영 단독 진입점과 별도 중복 requirements는 통합 앱과 루트 requirements로 대체했습니다.
- `slp/config.py`에서 DB·CSV·런타임 위치를 설정합니다. `sys.path`를 수정하는 연결 코드는 제거했습니다.
- 캐시·생성 리포트·경영 조회 설정·API 검증 결과는 `runtime/`로 분리하고 Git에서 제외합니다. 기존 경영 조회 설정이 필요하면 `report_settings.json`을 새 런타임 위치로 복사하세요.
- 기존 예약 실행 함수의 고정 서버 경로를 현재 Python·저장소·데이터·런타임 위치로 변경했습니다. cron을 실제로 등록하거나 변경하지는 않았습니다.
- 계산식·판정 기준·AI 호출 계약은 유지했습니다. 화면과 계산이 섞인 개별 모듈의 추가 분해는 이번 변경 범위에서 제외했습니다.

실제 데이터·DB·원본 캐시·다운로드 결과·API 대화 원문·키·서버 로그는 이 저장소에 포함하지 않습니다. 검증은 기존 Python 3.12 가상환경에서 수행했습니다. 새 기기의 패키지 설치, 실제 브라우저의 픽셀 배치·인쇄 품질, 모델 답변 정확도, 장시간 운영 안정성까지 보장하는 결과는 아닙니다. 기존 NumPy 시간 단위 및 Streamlit 표시 옵션의 사용 중단 경고는 남아 있습니다.

## 실행 및 되돌리기

```bash
# 저장소 루트, 기존과 동일
bash run.sh

# 전체 테스트
python -m unittest discover -s tests -t . -p 'test_*.py'

# 운영 점검 (실제 키는 서버 환경변수로 주입)
python -m scripts.checks.check_agentstream
# 아래 명령은 실제 모델 호출과 토큰 사용이 발생합니다.
python -m scripts.checks.verify_agentstream
```

공용 서버 교체는 원래 프로세스의 실행 폴더·명령·환경을 메모리에 보관한 상태에서 진행했고, 새 서버의 기동·메뉴·다운로드 검증이 실패하면 기존 서버를 다시 시작하도록 했습니다. 검증이 통과하여 자동 복구는 실행되지 않았습니다. 정리 전 실행 폴더도 보관했습니다.

추후 문제가 생기면 GitHub에서는 폴더 정리 커밋을 `git revert <정리 커밋 SHA>`로 되돌릴 수 있습니다. 백업 브랜치는 정리 직전 소스를 확인하는 용도이며 이후 동료의 커밋을 덮어쓰는 강제 푸시는 피하세요. 서버는 별도로 이전 실행 폴더와 안전한 API 키 주입 환경으로 복구해야 합니다. GitHub의 커밋을 되돌리는 것만으로 실행 중인 서버가 자동 복구되지는 않습니다.
